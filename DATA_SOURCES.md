# Политика источников данных

Проект не поставляет региональные наборы данных. Для каждого подключённого слоя
региональный `SOURCES.md` должен содержать:

- название владельца и точный URL источника;
- дату получения и дату актуальности;
- лицензию и право повторного распространения;
- способ получения и параметры фильтрации;
- SHA-256 исходного snapshot;
- преобразования и ограничения качества;
- ответственного за ручную проверку.

Данные OpenStreetMap требуют атрибуции и соблюдения ODbL. Коммерческие каталоги,
кадастровые сведения, фотографии и документы нельзя считать открытыми только
потому, что они доступны в браузере. Если право публикации не подтверждено,
храните исходник вне Git и публикуйте только разрешённый результат.
