# Локальные приватные данные

`legacy-snapshot/` содержит независимые копии 29 файлов старого региона,
включая PBF и исходные таблицы. Манифест фиксирует размеры и SHA-256.
`baseline/` и XLSX совпадают с этой копией; `osm-cache/` пересоздан из неё.
Обычная сборка не читает старую папку и не загружает данные из сети.

Предыдущие данные и внешние сведения сохранены отдельно для истории.
Данные не входят в Git; необходим отдельный резервный архив.
Подробности: [LOCAL_DATA_SETUP.md](../LOCAL_DATA_SETUP.md).
