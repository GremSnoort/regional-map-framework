# Приморский край

Активный автономный набор данных плотности подготовлен строго из старого проекта
`GAB/X5Group/analytical_maps/primkrai`. Старые файлы не изменяются.
Все входы находятся в новом региональном каталоге; сборка работает без сети
и без доступа к старой папке. Данные исключены из Git и не отправляются в GitHub.

Текущая версия адресных сопоставлений жилого фонда — v3, указатель
`sources/housing-current.json`. Она включает опубликованные первичные
источники и хранится отдельно от весов плотности. Независимая кадастровая
привязка и актуальная заселённость пока не подтверждены.
Предыдущие документы аудита и внешней перепроверки сохраняют историю
прошлого этапа; политика основной плотности описана в LOCAL_DATA_SETUP.md.
На карте дополнительный слой жилья выключен по умолчанию.
Основной локальный pipeline остаётся draft. На VPS 06.10.2026 подключён
отдельный проверенный пакет из десяти слоёв; сведения о бэкапе и откате —
в отчёте деплоя выше.
