# Автономный набор данных Приморского края

Активный набор подготовлен 05.10.2026 **строго из региональных файлов старого
проекта** `GAB/X5Group/analytical_maps/primkrai`. Старый проект используется
только как источник чтения при создании копии. Обычная сборка его не открывает.
Новые загрузки, новые даты статистики и внешние характеристики домов не добавлены.

## Хранение в новом проекте

| Каталог | Содержание и назначение |
|---|---|
| `sources/legacy-snapshot/` | Независимые копии 29 исходных региональных файлов, включая старые опубликованные слои, исходный PBF, XLSX, HTML каталога магазинов, настройки и манифесты |
| `sources/legacy-snapshot-manifest.json` | Размеры и SHA-256 всех копий, исходные даты изменения; доказательство неизменности файлов при переносе |
| `sources/baseline/` | Семь исходных слоёв, побайтно совпадающих с `legacy-snapshot/data/` |
| `sources/*.xlsx` | Рабочие копии старых таблиц Росстата, без обновления содержания |
| `sources/osm-cache/` | Повторное извлечение 411 886 зданий и 12 границ из локальной копии старого PBF; модельные области очереди проверки |
| `sources/local-derived-manifest.json` | Контрольные суммы извлечённых и производных материалов |
| `review/housing-register.json` | Производная очередь проверки 6 566 контуров в трёх пунктах; только сведения OSM |
| `pipeline/outputs/` | Результаты сборки, таблицы источников и проверки качества |
| `data/` | Готовые слои для карты; заменяются успешной сборкой через staging |
| `sources/previous-reviewed-20261005/` | Предыдущий набор слоёв для сравнения и отката внутри нового проекта |
| `sources/external-evidence-20261005/` | Ранее найденные внешние сведения, выключенные из активной сборки |

В `sources/legacy-snapshot/` нет символических или жёстких ссылок на старые
файлы. Старую папку можно убрать с машины сборки: все необходимые входы уже
локальны. Старый каталог в манифесте — запись происхождения, не рабочая зависимость.
Не выполняйте старые скрипты из snapshot: это сохранённые материалы, а не новый pipeline.

**Данные не отправляются в GitHub.** `data/`, `sources/`, `review/`, outputs
и рабочие манифесты исключены из Git. В Git остаются код и документация;
`INPUT_PROVENANCE.json` содержит описания и контрольные суммы, без геоданных.
Ничего не было закоммичено или отправлено. Для восстановления данных нужен
отдельный резервный архив нового регионального каталога; Git-клона недостаточно.

## Какие улучшения выполнены

- Сохранённые таблицы Росстата сопоставлены с объектами карты по точным листам
  и ячейкам. Исправлены контроли Спасского, Углекаменска и Горных Ключей
  на основании **тех же старых XLSX**.
- Площадь муниципалитетов и обрезанных ячеек вычисляется на эллипсоиде WGS84.
- Локальная сетка использует общую метрическую систему, непересекающиеся
  области и точные пересечения контуров зданий с ячейками.
- Численность сохраняет контроль каждого пункта с точностью 0,001 человека.
- Официальные и неподтверждённые контроли населения разведены по слоям.
- Нежилые объекты исключаются по исходным тегам OSM. Повторяющиеся контуры
  не удваивают жилой вес; конфликтующие дубликаты исключаются.
- Качество локальной модели и допущения об этажности показаны отдельно.
  Есть расчёт чувствительности и таблицы для повторной проверки.
- Очередь жилья охватывает **все** контуры с внутренней точкой в модельных
  областях Монастырища (1 137), Ольги (2 138), Кавалерово (3 291), включая
  нежилые объекты и здания без адресов. Это позволяет проверять классификацию,
  а не считать каждое адресное здание жилым.

Контроли населения остаются на 2021/2025 годы, геометрия OSM — на 08.09.2026.
Обновление расчётов не означает обновление дат первичных данных. Границы малых
пунктов модельные, сведения о фактическом заселении не получены.

В строгом профиле **не применяется** прежнее внешнее исключение школы
Монастырища по адресу 453: в исходном OSM для этого контура нет соответствующего
тега назначения. Контур возвращён в категорию неоднозначных адресных зданий.
Предыдущие сведения сохранены в архиве; для подтверждения назначения нужен
отдельно разрешённый внешний источник. Также не применяются перечень МКД,
карточка mkdbase и сведения ГИС ЖКХ. Их отсутствие не подменяется нулевой
жилой площадью или условными подтверждёнными пятью этажами.

## Повторение сборки

Установить зависимости нового регионального pipeline в отдельное окружение:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r regions/primkrai/pipeline/requirements-lock.txt
.venv/bin/python regions/primkrai/pipeline/verify_local_setup.py --region-root regions/primkrai
.venv/bin/python -m unittest discover -s regions/primkrai/pipeline -p 'test_*.py'
.venv/bin/python manage.py build primkrai
.venv/bin/python manage.py doctor primkrai
```

Проверка `verify_local_setup.py` читает только файлы нового регионального
каталога. Она отклоняет изменённые snapshots, несовпадение рабочих входов
со старой копией, символические ссылки, выход путей за пределы региона,
внешние ручные исключения и подтверждённые извне характеристики жилья.
Каждый запуск сборки выполняет эту проверку; обращения к сети не требуются.

Повторить извлечение зданий и подготовку очереди после осознанного изменения
локальных входов (всё выполняется в новом проекте):

```bash
.venv/bin/python regions/primkrai/pipeline/extract_osm.py \
  --pbf regions/primkrai/sources/legacy-snapshot/sources/cache/far-eastern-fed-district-latest.osm.pbf \
  --municipalities regions/primkrai/sources/baseline/municipalities.geojson \
  --config regions/primkrai/pipeline/legacy-density-config.json \
  --output regions/primkrai/sources/osm-cache
.venv/bin/python regions/primkrai/pipeline/prepare_housing_queue.py --region-root regions/primkrai
.venv/bin/python pipeline_core/runner.py --region-root regions/primkrai --write-lock
.venv/bin/python manage.py build primkrai
```

Изменять исходный snapshot для устранения ошибки нельзя: исправления должны
быть отдельными производными преобразованиями с объяснением происхождения.
Не обновляйте input lock только для обхода ошибки контроля источников.
Новый регион остаётся `draft`; деплой VPS в этой работе не менялся.
